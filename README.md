# Malaysia Festival Media Planner

Initial MVP for a club media team to track Malaysian festivals and poster preparation.

## MVP

- Festival dashboard
- Poster task statuses: Pending, Ongoing, Done, Overdue
- Assignment and deadline tracking
- Poster/Canva links and task notes
- Direct image/PDF poster uploads via Supabase Storage
- User-scoped poster file access policies
- Team roles and status filtering
- Task search across festival, assignee, deadline, and notes
- Live dashboard workload statistics
- Live priority deadlines from poster tasks
- Team directory and account settings pages
- Searchable team directory
- Sample Malaysian celebrations

## Next integrations

- Supabase authentication, database, and poster storage
- Daily AI-assisted festival discovery
- Email reminders
- Google Calendar events

## Run

Open `index.html` in a browser for the initial prototype.
